## Acceptance gate

```gate
lint_typecheck_exit_code == 0
evidence: status/evidence/T1.json
key: lint_typecheck_exit_code
```

Write the measured value to `status/evidence/T1.json` as `{"lint_typecheck_exit_code": <number>}`, commit it, then record the row in the plan's Evidence log with the command that produced it.

An evidence gate asserts the number against the threshold, so it cannot pass
vacuously — a missing evidence file is a hard failure, not a skip. It also runs
no build tooling, which matters for tasks that run before the scaffold exists.
