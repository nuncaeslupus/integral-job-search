# T28: Continuous profile capture across every phase

## Acceptance gate

```gate
profile_capture_coverage == 1.0
evidence: status/evidence/T28.json
key: profile_capture_coverage
```

```bash
uv run python -m jobsearch.profile_capture --write-evidence status/evidence/T28.json
```

## What this is

The profile fills during onboarding today. It should fill during *everything*:
reviewing a ranking, rejecting an offer with a reason, reacting to ad text,
rehearsing for an interview. Anything the candidate says about themselves is
evidence about them, and accrues the way conversational memory does
(`status/plan.md`, Scope extension §4).

T6's append-only `evidence.jsonl` is the substrate and needs no change. What is
missing is that every candidate-facing surface writes to it, with provenance
(which surface, when, in response to what) so a later reader can weigh a
throwaway remark differently from a considered interview answer.

`profile_capture_coverage` = the fraction of candidate-facing surfaces that
accept free text and append at least one evidence row. A surface that takes
input and records nothing fails the gate — that is the whole point.

## Watch for

Capturing everything is also a privacy surface. The spec calls the profile store
the most sensitive artefact in the system and the story bank per-episode
`disclosure: private` by default. Continuous capture must not quietly widen what
is stored or shared; evidence rows inherit the same default.
