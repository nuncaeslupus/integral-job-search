## What this is

`docs/distribution.md` §6 — connectors flow both ways, and the tool does the
work so the candidate does not have to know what a pull request is.

**Coming in.** When sourcing needs a site with no connector, the tool reads the
sources repository's manifest over plain HTTPS — no account, no
authentication — and reports what it found, with provenance: who contributed it
and when it was last verified. If the candidate accepts, it installs into
`$INTEGRAL_HOME/connectors/` (the user's directory, never the clone) and runs
its fixture test **before first use**. A stale connector fails there, and
repairing it is the same work as writing one.

**Going out.** Having written or repaired one, the tool offers to contribute it.
Before anything is sent it states: which files would go (connector, sampled
fixture, metadata), that the contribution is public and carries their GitHub
username, that **nothing about them, their profile or their search is
included**, and that declining costs nothing. On acceptance the agent does the
whole of it — fork, branch, pull request — and CI re-runs the test their machine
already passed.

**Declining is a complete outcome, not a fallback.** The connector stays
installed and working, the offer is not repeated for that connector, and someone
else will contribute one eventually. This is process spec §5.4's non-insistence
rule applied to contribution: it is better to have fewer connectors than to
press someone who said no.

**Without a GitHub account**, in order of friction: walk them through
`gh auth login`; or open a prefilled issue form in their browser; or write the
bundle to `$INTEGRAL_HOME/outbox/<site>/` and leave it there. No anonymous
submission endpoint — it is the only option that requires running and defending
a service, and volume does not justify one.

## Tests

`test_nothing_leaves_the_machine_without_an_explicit_yes` in
`tests/test_connector_exchange.py`;
`test_the_disclosure_lists_every_file_that_would_be_sent`;
`test_declining_leaves_the_connector_installed_and_is_not_asked_again`;
`test_no_profile_path_is_read_by_the_contribution_path` — the bundle cannot
carry candidate data because it never reads any;
`test_an_installed_connector_runs_its_fixture_before_first_use`.
