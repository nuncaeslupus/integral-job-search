## Acceptance gate

```gate
connector_fixture_parse_f1 >= 0.95
evidence: status/evidence/T12.json
key: connector_fixture_parse_f1
```

Write the measured value to `status/evidence/T12.json` as `{"connector_fixture_parse_f1": <number>}`, commit it, then record the row in the plan's Evidence log with the command that produced it.

An evidence gate asserts the number against the threshold, so it cannot pass
vacuously — a missing evidence file is a hard failure, not a skip. It also runs
no build tooling, which matters for tasks that run before the scaffold exists.
