## What this is

T32 settled the connector **format** — declarative, data not code, no stored
credential. This settles what a connector must satisfy to be *shared*, so that
review is mechanical and an agent on someone else's machine can write one that
passes without asking anybody.

The shape (`docs/distribution.md` §5):

```
connectors/<site-id>/
  connector.yaml     what to fetch, and the mapping to the offer schema
  parse.py           optional, only where the declarative form cannot express it
  fixture/           one recorded response, saved verbatim
  meta.yaml          site, country, language, maintainer handle, last_verified
```

Six rules, in one command both a contributor's agent and CI run, so a green
local check and a green CI are the same judgement:

1. one connector, one directory, exactly those files;
2. a fixture is present, and the connector's output over it satisfies the offer
   schema **offline** — no fixture, no merge;
3. no network of its own: only the runner's HTTP client, which owns rate
   limiting, robots.txt, timeouts and the user agent (checked statically);
4. no filesystem writes, no subprocess, no environment or credential reads;
5. `meta.yaml` complete, including `last_verified`;
6. policy: public listings only, robots.txt respected, no authentication,
   paywall or captcha bypass.

**The fixture is a listing sampled for the purpose, never an advert the
candidate was reading.** Adverts are public; the *set* of adverts a person reads
is not — it carries their field, level, city and the fact that they are looking.
A fixture in a public repository carries whatever made it, permanently. So the
recorded response must declare its provenance as a sampled fetch and carry
nothing about who asked for it, and a fixture that fails that check is rejected.

CI never reaches the network: fixtures only. Deterministic, and nobody's pull
request turns the project's CI into a scraping proxy.

## Out of scope

Creating the separate repository itself, and moving connectors into it. This
task defines and enforces the contract; the split is a follow-up once there is
more than one connector to move.
