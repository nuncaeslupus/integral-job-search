# T14: Lexical prefilter (recall-oriented) ahead of LLM extraction

## Acceptance gate

```gate
prefilter_recall >= 0.98
evidence: status/evidence/T14.json
key: prefilter_recall
```

```bash
echo "no gate command defined for T14 — replace this line with the command that writes status/evidence/T14.json" >&2; exit 1
```

The two blocks do different jobs and both are required. The `bash` block
regenerates `status/evidence/T14.json`; the `gate` block asserts the
number in it against the threshold. Without the first, a stale or hand-written
evidence file passes unchallenged; without the second, a command that exits 0
counts as a gate whatever it measured.

The default command fails on purpose. A task whose measurement is undefined has
not passed its gate — it has not been measured. Replace it as part of the work.

## Scope change — read this before computing `prefilter_recall`, 2026-08-19

T5 closed without the hand-labelling campaign it was once going to supply
(`lo-d2b2`). The named test for this task — "the prefilter drops no ad the
corpus labels positive for any dimension" — is measured against those labels,
and `status/evidence/T5.json` says what there are:

```
label_count               39, over 4 ads
labels_by_split           elicitation 25 · evaluation 14
labels_by_dimension       no dimension above 4; most at 1–3
dimensions_without_labels mission_alignment, process_formality,
                          social_intensity, work_intensity
```

A recall figure over 14 evaluation labels is noise wearing a threshold. **Do not
compute `prefilter_recall >= 0.98` against them and record a pass.** Apply the
same rule D-2 (`lo-77a6`) sets for T15: report `n` beside the number, refuse to
emit the number at all below the label floor, and name the dimensions that could
not be measured. A gate that cannot be measured yet is unmeasured — not passed,
not failed.

### Consider folding this into T15 instead

T15's own v2 scope note already describes staged extraction: normalise, take
what patterns and keyword rules can take outright, and send a model only what
they could not settle. That middle stage **is** this prefilter. Kept as a
separate task it needs its own gate against a corpus that cannot support one;
folded into T15 it is a stage measured by T15's gate, which D-2 has already
taught to handle a thin label set honestly.

Folding is the recommendation. It is a scope decision rather than a mechanical
one, so it needs the owner's word before the task is closed as absorbed — raise
it rather than deciding it inside a worker run.
