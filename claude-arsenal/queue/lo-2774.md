# T3: Dimension model v0: 20–25 dimensions with ES/EN/CA cues and elicitation questions

## Acceptance gate

```gate
dimension_extractor_coverage >= 0.90
evidence: status/evidence/T3.json
key: dimension_extractor_coverage
```

Write the measured value to `status/evidence/T3.json` as `{"dimension_extractor_coverage": <number>}`, commit it, then record the row in the plan's Evidence log with the command that produced it.

An evidence gate asserts the number against the threshold, so it cannot pass
vacuously — a missing evidence file is a hard failure, not a skip. It also runs
no build tooling, which matters for tasks that run before the scaffold exists.
