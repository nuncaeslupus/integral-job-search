# T71: Read the robots policy with a browser agent when the honest one is refused

## Acceptance gate

```gate
robots_policies_abandoned_on_refusal == 0
evidence: status/evidence/T71.json
key: robots_policies_abandoned_on_refusal
```

```bash
uv run --extra dev pytest tests/test_robots.py -q
uv run --extra dev python -m integral.robots
```

`src/integral/robots.py` must write `status/evidence/T71.json`. This is a new module, so it owns this record outright. **A gate must never name a file no module produces** — the file not existing yet is the honest state of an unstarted task; the file existing but empty of this metric is not.

The `bash` block regenerates it; the `gate` block asserts the number in it.

## Why

Some sites put a WAF in front of everything, so an honest agent string gets 403 on `/robots.txt` itself. Today that leaves us with no policy, and no policy currently reads as no restriction.

The rule, adapted from the upstream repository: *a policy you are prevented from reading cannot be honoured, and `robots.txt` is not the protected resource.* So the policy document — and only it — may be refetched with a browser user-agent, and what comes back is then **obeyed more strictly, not less**.

## What it must not become

**This is not a block-evasion hatch and must not become one.** Exactly one URL per host is eligible: its `/robots.txt`. Content is never refetched with a different agent — a 403 on an advert stays `unverified` (T74's concern), and that is the correct answer.

Record the reasoning in the docstring: the intent is what stops a later reader from 'generalising' this to content fetches.

**A zero-violation count over an empty input set is not a pass.** The gate counts
violations, and nothing counted is also zero — so the evidence record must carry
`robots_policies_abandoned_on_refusal_evaluated` (refused-policy fixtures evaluated) and the gate is only meaningful while that count is
non-zero. This is the failure this whole increment is about, turned on its own gates:
a check that reports success over work it did not do. Assert the denominator.

## Tests — write these RED first

`test_a_403_on_the_policy_is_retried_with_a_browser_agent` in `tests/test_robots.py`.

`test_only_the_policy_url_is_refetched_never_content` — the retry is scoped to the `/robots.txt` URL and nothing else.

`test_a_recovered_policy_is_obeyed_not_ignored` — a policy recovered this way is applied, including when it disallows us.

`test_the_gate_does_not_pass_on_an_empty_input_set` — assert `robots_policies_abandoned_on_refusal_evaluated` is written and non-zero.
