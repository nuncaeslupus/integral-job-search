## Why

**Run this task last** — it records what the others actually took.

`README.md` gains an **Acknowledgements** section naming [`MadsLorentzen/ai-job-search`](https://github.com/MadsLorentzen/ai-job-search) (MIT, © 2026 Mads Lorentzen), and `docs/METHODS.md` gains one entry per borrowed technique naming its upstream source and its limits. METHODS already exists to record where a method came from and what is not known about it; this is that register doing its ordinary job.

MIT requires notice retention for copied code, not attribution for ideas — this is a commitment the owner made, not a licence obligation. If any actual code was lifted (the robots matcher is the likely candidate), retain their MIT notice in that file.

## What it must not become

Do not credit upstream for T85 or for anything this repository worked out itself — an over-broad acknowledgement is as misleading as a missing one.

Record the **limits** too, not only the source: the upstream scoring rubric was assessed and rejected, and METHODS is where that judgement belongs so nobody re-imports it later.

**A zero-violation count over an empty input set is not a pass.** The gate counts
violations, and nothing counted is also zero — so the evidence record must carry
`borrowed_techniques_without_attribution_evaluated` (borrowed techniques listed) and the gate is only meaningful while that count is
non-zero. This is the failure this whole increment is about, turned on its own gates:
a check that reports success over work it did not do. Assert the denominator.
