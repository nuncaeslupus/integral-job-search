`Probe.counted_but_never_read` decides the divergence T122 measures from two
signals: what the run **says** (`reported_never_read`) and what the run **did**
(counted a gate and went green over an evidence file that does not exist).
Neither subsumes the other, and #425 pinned each with its own fixture.

The hole is what happens when **both** the classifier and the first signal are
gone at once. Remove `reported_never_read` and revert `gate_declaration`'s
`unreadable` branch, and every arrangement comes back False: the reverted
verifier is red about the divergence, so `green` is False and the second signal
never fires either. `gates_counted_as_asserted_but_never_read` reads **0** and
`python -m integral.gate_reader_agreement` exits **0** over a defect that is
fully back. Measured by the second reader on #425, not reasoned.

**The protection is real and it does not live in the metric.** In that state ten
of the module's twenty-three fixture cases go red and `make host-gate` is
`12 failed, 3214 passed`, so the defect cannot reach `main` unnoticed. What is
wrong is narrower and worth naming exactly: the *number this task's gate
re-asserts for the life of the task* is not the thing doing the protecting, and
anybody quoting it as though it were is quoting a value that a two-mutation
state leaves clean.

## The rule this task has to adopt

**Counted at all, or green.** A run that counted a gate over an evidence file
that cannot exist has diverged, whatever else it reports and whatever its exit
status: a checker that read the block must have failed on the missing file, so
`counted_as_asserted > 0` is by itself the divergence for these fixtures. That
subsumes both of today's signals — the honest-but-wrong verifier counts, and the
silent green verifier counts — and it is why the hole closes rather than moving:
there is no state left in which a reverted classifier still counts the fence and
the property returns False.

It is a **redesign of the detector**, which is why #425 deferred it rather than
folding it into a rework round that already had a green gate in hand. Eight of
T70's ten defects were introduced by the session fixing the previous one, and
the change here rewrites the exact property that four review rounds have been
arguing about. It is reviewed as its own diff or not at all.

Two things the redesign must not lose, both currently earned by the two-signal
form:

* the **controls** must stay red. `second_fence_after_the_first` and
  `label_in_a_later_section` also count a gate, so a rule of "counted at all"
  applied without the `carries_a_readable_gate` split turns both controls into
  divergences and zeroes nothing — the vacuous pass in a new spelling.
* the **board half** reads a real verifier over the real board, where an
  evidence file legitimately exists and a counted gate is not a divergence. The
  simpler rule is a statement about the *fixtures*, whose evidence path is
  absent by construction, and must not be applied to the board's report.

## What the metric counts

`reverted_defects_the_metric_reads_as_clean` is the number of enumerated
detector states in which the T122 defect is **present** and
`gates_counted_as_asserted_but_never_read` nonetheless reads 0. The states are
the classifier reverted, crossed with {detector intact, first signal removed,
second signal removed, silent-pass catch removed}, plus each single mutation on
its own. Every one of them is drivable with machinery the module already has:
`probe(arrangement, verifier)` takes an arbitrary verifier path, so a mutated
copy written to a temporary directory is a first-class input and no state has to
be asserted about rather than run.

Today's code fails it by construction — the two-mutation state is one of the
enumerated states and reads 0 — which is what makes it a gate rather than a pin.

The denominator is `detector_states_probed_at_least`, a **floor** in the
`naming.MINIMUM_SCANNED` style (T100) and at least 6, because a clean zero
reached by enumerating fewer states is the defect wearing the fix's clothes.
Named after the wrong outcome per T123: the head noun is *defects the metric
reads as clean*, an occurrence that can be counted, not a category.

## The wider shape, recorded here because it is the same finding

Three further mutations of T122 leave the metric at 0 while the fixtures do all
the work: downgrading `gate_declaration`'s `unreadable` branch to `absent`
(R1 on #425, killed by 12 cases, metric 0), and the two halves of `measure`
that #425 blocked on. The last two were closed on that PR by pinning every
finding `measure` reports to the inputs it is computed from. This task is the
residue: the one place where the *fixtures* are the whole protection and the
number is decorative. A metric that reads 0 in a state its own fixtures call red
is not a second check on them; it is a value that happens to agree.
