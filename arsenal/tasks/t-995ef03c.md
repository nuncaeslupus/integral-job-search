## Acceptance gate

```gate
end_to_end_replay_defects == 0
evidence: status/evidence/T149.json
key: end_to_end_replay_defects
```

```bash
uv run --extra dev pytest tests/test_end_to_end.py -q
uv run --extra dev python -m integral.end_to_end
```

The tool has now been run once from the first question to a sent application:
identify, intake, constraints, history, traits, sourcing, liveness, filtering,
ranking, reactions, and document generation. Only step 12, interview
preparation, is untouched. That run produced thirteen document revisions, each
carrying a judgement the candidate made and explained.

None of it is a fixture, and today **a step skill can be changed and nothing
notices until a live session goes wrong**. There is no replay of the whole
sequence anywhere in the repository; every gate measures one step.

The run itself cannot be committed. It lives in one real person's tree under
`~/.integral-job-search/`, and the rule that keeps this repository free of a
real candidate's data is not negotiable — `tests/fixtures/generation/master.json`
exists precisely so there is a stated fictional candidate to measure against.

So this is a **translation, not a copy**: the *shape* of the run becomes a
fixture over the fictional candidate — the step sequence, the artefact each step
produced, the revisions and what each one changed — while the real tree stays
where it is. What it buys is a regression case covering every step at once, at
the level where the failures actually happened: not "does this function return",
but "did step 9 hand step 10 something step 10 could use".

Worth carrying across deliberately, because each was learned by being got wrong:

- the sequence a live run actually took, including the steps that were revisited;
- what each document revision changed and why, since that is the record of how a
  draft becomes a sent document;
- the artefacts whose absence broke something — the `to` block, the claim
  manifest, the style sheet the render actually used.

Interview preparation is out of scope here: it has never been run, so there is
nothing to freeze. It joins the fixture when it has.
