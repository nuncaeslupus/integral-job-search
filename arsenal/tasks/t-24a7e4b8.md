Source: Manfred Tech Career Report 2026, which publishes salaries by role, seniority and company type at https://www.getmanfred.com/tech-career-report/tcr-2026.json (with informe-es.md / informe-en.md).

## Wanted

When an offer publishes no range, or the candidate asks what a role pays, the tool can show the report's reference band for that role, seniority and company type, cited as "Manfred Tech Career Report 2026".

The data is CC BY-NC and this repository is MIT, so it is **fetched at runtime and cached only in the candidate's local profile tree, never committed to the repository**: no fixture, corpus or evidence file may carry its values. Tests use a small synthetic payload with the same shape. Robots is checked with `integral.robots.Robots().allows` before the fetch; a refusal or a failed fetch shows nothing rather than a guess.

## Tests

`tests/test_reference_salaries.py`: lookup by role/seniority/company type over a synthetic payload; an unknown role returns nothing; a robots refusal fetches nothing; the cache path is under the profile root, never under the repository.

## Acceptance gate

```bash
uv run --extra dev pytest tests/test_reference_salaries.py -q
```
