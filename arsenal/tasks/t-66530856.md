# T80: The ATS text-layer contract, asserted over the document text

## Acceptance gate

```gate
documents_missing_a_required_text_layer_field == 0
evidence: status/evidence/T80.json
key: documents_missing_a_required_text_layer_field
```

```bash
uv run --extra dev pytest tests/test_ats.py -q
uv run --extra dev python -m integral.ats
```

`src/integral/ats.py` must write `status/evidence/T80.json`. This is a new module, so it owns this record outright. **A gate must never name a file no module produces** — the file not existing yet is the honest state of an unstarted task; the file existing but empty of this metric is not.

The `bash` block regenerates it; the `gate` block asserts the number in it.

## Why

The generated CV is the one artefact in this system that reaches a stranger, and nothing checks that a machine can read it. An applicant-tracking system parses the **text layer**: contact details carried only by an icon glyph or a hyperlink are invisible to it, and so are dates that only exist as layout.

**Asserted over the document text, deliberately renderer-independent.** T45 (merged) produces Markdown with a claim manifest; no PDF renderer exists yet and one is deferred until a live session needs it (owner, 2026-08-25). Writing the contract now means the same assertions run over `pdftotext -layout -enc UTF-8` output the day a renderer lands — and the `-enc UTF-8` matters here more than upstream, because Xpdf builds default to Latin-1 and this candidate's documents carry Catalan and Spanish accents.

## What it must not become

**This must not become a check that passes because there is nothing to check.** That is the D-21 shape — artefact presence standing in for a check nobody ran. Assert over a real generated document from `cv/generated/`, and make the test that proves a *missing* field fails, not only that a complete one passes.

Shell out to `pdftotext` only if a PDF is actually present. Nothing in this task creates one.

**A zero-violation count over an empty input set is not a pass.** The gate counts
violations, and nothing counted is also zero — so the evidence record must carry
`documents_missing_a_required_text_layer_field_evaluated` (generated documents checked) and the gate is only meaningful while that count is
non-zero. This is the failure this whole increment is about, turned on its own gates:
a check that reports success over work it did not do. Assert the denominator.
