Source: Manfred Tech Career Report 2026, which reports that technical interviews now commonly allow or expect AI assistants, and names the formats that replaced the classic whiteboard.

## Wanted

Step 12's preparation (`step-12-interview-log`, mock interview) offers a drill for each of four formats, chosen from what the advert or the recruiter said about the process:

1. live coding with an AI assistant allowed (judged on how the candidate directs and checks it);
2. reviewing AI-generated code that contains planted bugs;
3. a take-home done with AI, then defended live;
4. a problem whose requirements change mid-session, or a system-design discussion.

Each drill is offered, never imposed, and works the same in Spanish, English and Catalan.

## Tests

`tests/test_interview_formats.py`: each format is selectable and produces a drill; a process description naming a format selects it in all three languages; an advert naming none offers the choice rather than picking one.

## Acceptance gate

```bash
uv run --extra dev pytest tests/test_interview_formats.py -q
```
