## Acceptance gate

```gate
extraction_macro_f1 >= 0.75
evidence: status/evidence/T15.json
key: extraction_macro_f1
status-key: extraction_status
```

```bash
uv run --extra dev pytest tests/test_extract.py -q
uv run --extra dev python -m integral.extraction
```

The `bash` block regenerates `status/evidence/T15.json`; the `gate` block
asserts the number in it. **`status-key` is what makes this task honest while
it waits**: until the corpus supports the number, `integral.extraction` records
`extraction_macro_f1: null` beside `extraction_status: "unmeasured"`, and
`gate_evidence.py` exits 3 — "the check ran, and what it found is that this
cannot be scored yet". That is not a pass and not a fail, and it is the state
this task is in on the day it is filed.

## Why this is its own task

Split out of T15 (`lo-25b1`) by **D-12 (`t-e1ca8374`, #83)**, 2026-08-22. T15
built the staged extractor and could show that it is not broken —
`prefilter_suppressed_positives == 0` over 36 positives — but not that it
scores well, because scoring needs labels that do not exist yet:
`status/evidence/T15.json` records 14 evaluation labels against a floor of 10
per dimension, `scorable_dimensions: []`, and every dimension below the floor.

Held together, one unmeasurable number kept fifteen of the twenty-six live
tasks blocked. Held apart, T15 closes on what T15 built and this task waits
where it belongs — behind the corpus work.

## What it must not become

The three requirements D-2 (`lo-77a6`) placed on this number are carried here
unchanged, and none of them is negotiable to make the gate go green:

1. **Score only what a person decided.** `extraction_macro_f1` is computed over
   `Label` rows whose `source` is `human`, `confirmed` or `edited`. Never over
   `corpus/labelled/suggestions.json`, and never over `extraction.gold`.
2. **Refuse to emit the number below the label floor.** Too few human labels
   for a dimension means that dimension is *unmeasured*, named as such in the
   evidence file, rather than carrying a figure computed from three rows.
3. **Emit `n` beside every score**, per dimension and in aggregate.

**Do not resolve this by relaxing the floor, or by scoring cue-derived gold as
if a person had placed it.** Both make the number appear without making it
true, which is why D-2 exists.
