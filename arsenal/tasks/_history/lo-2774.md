## Acceptance gate

```gate
dimension_extractor_coverage >= 0.90
evidence: status/evidence/T3.json
key: dimension_extractor_coverage
```

```bash
uv run python -m jobsearch.dimensions --coverage status/evidence/T3.json
uv run --extra dev pytest tests/test_dimension_content.py -q
```

The two blocks do different jobs and both are required. The `bash` block
regenerates `status/evidence/T3.json`; the `gate` block asserts the
number in it against the threshold. Without the first, a stale or hand-written
evidence file passes unchallenged; without the second, a command that exits 0
counts as a gate whatever it measured.

`--coverage` refuses to report a number over an unloadable model (exit 3): a
coverage figure computed over dimensions that do not satisfy the schema would be
a measurement of something that does not exist. Gold examples are verified
verbatim against `corpus/raw/ads.jsonl` as part of the same run.
