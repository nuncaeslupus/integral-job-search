## What this is

`docs/product-shape.md` argued the shape: a conversation moves the tool, steps
are skills, checkpoints are scripts with numbers, state is files so it resumes.
That argument stands. Its **step table is superseded by specification v2**.

What this task owes is that no part of the shape is left as a question nobody
wrote down — measured, not asserted:

1. **every step has a named checkpoint** in `status/spec-v2-steps.json` — a
   metric, an operator, a threshold and an explicit state. `not_implemented` is a
   recorded value; a blank metric is indistinguishable from a forgotten one;
2. **every question the shape document opened carries a decision or a named
   blocker.** "Blocked" is a legitimate answer; silence is not.

`src/jobsearch/product_shape.py` measures both and writes
`status/evidence/T29.json`. A missing register reports `-1`, never the zero an
empty scan would otherwise produce.

## Decided

Recorded in `docs/product-shape.md` ("What needed deciding") and, for
distribution, in `docs/distribution.md`:

- **sittings** — several, resumable (spec v2 §5.1, §5.3);
- **traits** — held until two episodes on two occasions (spec v2 §2.2);
- **multi-user** — yes, from day one (spec v2 §6);
- **distribution** — installed by cloning; candidate state resolves from
  `$INTEGRAL_HOME` and is refused anywhere inside a git work tree; job-site
  connectors live in a separate repository; contributing one is offered,
  disclosed in full, and may be declined without consequence. This answers
  process spec §11.5;
- **name** — blocked, and named as blocked. "integral" is the direction;
  nothing depends on the final string.

The implementation the decision implies is **not** this task: the state
resolver (T51), the first-run bootstrap (T52), the connector contract (T53) and
the connector exchange (T54) each carry their own gate.
