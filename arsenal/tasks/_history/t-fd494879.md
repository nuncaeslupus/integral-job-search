## What landed

`src/integral/sourcing.py` — the missing middle. It reads `constraints.json` for
the candidate's country, selects the usable packages serving it, fills each
board's `{query}` from `candidate.Aim`, adjudicates robots **per URL before the
request is made**, fetches, classifies the response, parses with
`collect_listing`, builds offers and writes them through `collect_offer`.

## Three distinctions it refuses to blur

Each one, collapsed, turns a failed run into a run that merely looks empty:

* **Searched, versus handed everything.** A board with a `{query}` slot is asked
  the candidate's question; one without returns its whole list. Both are useful
  and they are not the same result.
* **Refused, versus empty.** `connector_health.rate_limited` decides, and its
  asymmetry is load-bearing: the status decides on its own, body markers are
  consulted only when nothing parsed. A board that refused us is not a board
  with no jobs.
* **Untrusted, versus empty.** `collect_listing` reports a stale connector, and
  a stale connector's empty page is not evidence about the market.

A fourth was added *because the live run exposed it*: a row the schema refuses
is dropped with **its reason**, not merely counted. `getmanfred_es` parsing 22
rows and producing 0 offers is a diagnosis; "22 items, 0 added" is a riddle.

## Two refusals that must not fail open

* **robots is consulted per URL, before the request.** A board that disallows
  one path may allow another, so the check cannot be hoisted to the board.
* **An unreadable robots.txt refuses.** Failing open there would fetch exactly
  the paths nobody could confirm we may. Pinned by a test whose fetcher raises.

`robots` is injectable and **defaults to a real adjudicator**, so the honest
thing happens without a caller remembering to ask. A test passes one whose
fetcher is a fixture — never `None` to mean "skip", which would make the safe
path the one you opt into.

## Deliberately not in scope

**Detail pages are not fetched.** That is why `getmanfred_es` contributes
nothing and `trabajos_es` loses 28 of 40: their list pages carry no ad body, and
`Offer` refuses a blank one. Fetching each card's detail page multiplies requests
by the page size and needs the crawl-delay handling `robots.delay` exists for —
its own piece of work, filed separately rather than bolted on here. Four of six
Spanish boards work today; the two that do not, say why.

## The gate, and why it has a control

`sourced_offers_without_a_recorded_fetch` counts offers in a tree that no row of
`offers/_fetches.jsonl` accounts for. **The existing hand-placed offers fail it**,
which is the intended reading: they were never fetched by this tool and the
number should say so.

A count of "things that are wrong" is satisfiable by a function that always
returns the empty list — T123's subject. So the fixture plants one offer the way
every existing offer arrived and asserts it is **found**; if the control goes
undetected the gate reports `unmeasured`, never a pass. The run also has a floor:
a run that collected nothing proves nothing about how offers get recorded.
