Promoted from the candidate sessions of 2026-09-06..2026-10-16: a practice the assistant ran by hand (scratch scripts or profile conventions) that any candidate needs.

`approval.stage_send` copies the payload's documents only. Every real delivery so far was finished by hand:

- PDFs named for sending, from `identity.json` (`<First>-<Last>-CV.pdf`, `<First>-<Last>-Cover-Letter.pdf`), never `cv.pdf`;
- one combined PDF, **letter first**, for portals that take a single upload;
- the letter as plain text (`Cover-Letter.txt`) for portals with a text box.

Make `stage_send` produce that set from the approved payload, keep `verify_send` covering every file it writes, and update step 11's Outputs section. Depends in practice on T191 (the PDF pipeline).

Suggested gate: `send_folders_missing_a_sendable_document == 0`.
