Captured during a test session at step `ranking` (ledger `test-2026-08-20-a`).

> At this point, you didn't give links to real offers, so it is not clear what to do with that info.

Seven offers were presented with title, employer, pay and a verbatim citation, and no link — although
every stored record carried `url` and `source_ref`. The presentation dropped a field the store had.

The card template must render `offer.url`, and an offer with no URL must show that as a stated
absence rather than silently omitting the row.

Addressed in: `step-09-ranking`.


## Acceptance gate

```gate
ranked_offers_without_a_url == 0
evidence: status/evidence/T44.json
key: ranked_offers_without_a_url
```

```bash
uv run python -m integral.presentation
uv run --extra dev pytest tests/test_presentation.py -k url -q
```

What is counted is the defect itself — a stored record that *has* a URL whose
card does not show it — not the offers that genuinely have none. An advert with
no link is a gap in the source; a link the store held and the card dropped is
this bug, and only the second is something the template can commit. The fixture
still carries one of each, so `test_an_offer_with_no_url_shows_the_absence` has
a case to render and the number stays a measurement of the right thing.
