## The defect

Two committed tests assert that a floor is a **literal** rather than an
expression derived from the population it guards:

* `tests/test_verified_gate.py` — `test_the_floor_is_a_literal_the_table_cannot_drag` (#333, F3);
* `tests/test_gate_reader_agreement.py` — `test_the_floor_is_a_literal_the_population_cannot_drag` (T122, #425).

Both read the module's top-level statements. **A rebinding nested one block deep
escapes both** — measured on #425's fifth read:

```python
MINIMUM_ARRANGEMENTS_PROBED = 13  # the decoy the pin sees
if True:
    MINIMUM_ARRANGEMENTS_PROBED = len(ARRANGEMENTS) + 1  # what actually binds
```

51 tests pass. With one arrangement deleted it restores the pre-fix fail-open in
full: the evidence run exits **0**, silently, the record is relaundered to twelve
names, and the suite stays green at 49.

The newer pin survives **nine** other attack forms — `int()` and `sum()`
wrappers, top-level rebinding, an `IfExp`, an in-module alias, an imported
constant, and a plainly wrong literal — and fires a fail-*closed* false alarm on
an annotated literal. So the construction is sound and the gap is narrow. It is
still a gap, it is in **both** pins, and the older one has carried it since #333.

## Why it was not blocked on

The fifth reader named it with a one-line remedy and cleared the PR anyway,
reasoning that the escape needs a decoy literal kept deliberately alongside the
rebinding — which is not an accident anyone commits — and that #333's committed
precedent has the identical blind spot, so blocking T122 for it would hold one
PR to a standard the repository's own precedent does not meet.

That reasoning is recorded here rather than in a merge commit, because the
consequence of accepting it is this task existing.

## The remedy, already named

`ast.walk` in place of `.body`, so a rebinding at any depth is seen. Applied to
**both** pins — one implementation of the rule if that is possible, since two
readers where one belongs is the defect T122 itself exists to remove.

## What the metric counts

`literal_pins_a_nested_rebinding_escapes` is the number of committed
literal-pins for which a nested rebinding of the pinned constant, with a decoy
literal at top level, does not fail the pin.

The pins swept are the denominator, committed as a literal floor per T122's
finding. **Verify the metric reads at least 2 against today's tree before
writing the fix.**

that diff.
