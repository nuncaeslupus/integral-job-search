# T81: Keyword coverage against the posting, in four statuses

## Acceptance gate

```gate
posting_keywords_left_unclassified == 0
evidence: status/evidence/T81.json
key: posting_keywords_left_unclassified
```

```bash
uv run --extra dev pytest tests/test_ats.py -q
uv run --extra dev python -m integral.ats
```

`src/integral/ats.py` must write `status/evidence/T81.json`. This is a new module, so it owns this record outright. **A gate must never name a file no module produces** — the file not existing yet is the honest state of an unstarted task; the file existing but empty of this metric is not.

The `bash` block regenerates it; the `gate` block asserts the number in it.

## Why

A coverage report over the posting's keywords, in **four** statuses:

- `covered` — present in the document.
- `synonym-only` — present, but not in the advert's words.
- `missing (have it)` — the store holds it and the document left it out. **A document bug.**
- `missing (gap)` — the candidate does not have it. **A fact about the candidate.**

That fourth split is the whole value. Collapsing the last two into 'missing' is how CVs get padded: it makes a drafting omission and an honest gap look identical, and the obvious remedy for the pair is to invent the missing thing.

Maps onto T45's existing claim manifest nearly for free — the manifest already knows what the store holds and what the document used.

## What it must not become

**Never stuff keywords.** This report exists to inform a drafting decision and to be shown to the candidate, not to drive automatic insertion. A `missing (gap)` is something to say honestly in a letter or to walk away from — never something to quietly add.

**A zero-violation count over an empty input set is not a pass.** The gate counts
violations, and nothing counted is also zero — so the evidence record must carry
`posting_keywords_left_unclassified_evaluated` (posting keywords classified) and the gate is only meaningful while that count is
non-zero. This is the failure this whole increment is about, turned on its own gates:
a check that reports success over work it did not do. Assert the denominator.
