# T75: Dedup prefers the employer's own posting over an aggregator copy

## Acceptance gate


The `bash` block regenerates `status/evidence/T75.json`; the `gate` block asserts the
number in it.

## Why

`dedup.py` collapses duplicates by similarity and picks a survivor with no preference for where the advert came from. Aggregators routinely strip the requisition id and the grade — and the grade is the input `dimensions/seniority_expectation.yaml` reads. So when the aggregator copy wins, we silently lose a scored dimension, and D-19's 'settled nothing' logic then reads it as a vocabulary gap rather than a source problem.

## What it must not become

**Source rank is a tie-break among equals, not an override.** Liveness wins over source rank every time: a dead posting on the employer's own site is worth less than a live copy anywhere.

Do not hard-code a list of aggregator domains. Rank by what the connector already declares about itself, so a new connector does not need this module edited.
